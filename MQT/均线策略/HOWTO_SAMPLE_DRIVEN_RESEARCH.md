# 7/13/40 策略：样本驱动研究与迭代 HowTo

日期：2026-08-13

## 1. 为什么需要重建研究流程

现有人工样本不是无效，也不是用户必须一次把所有规则描述完整。问题在于此前把对话中的局部判断直接翻译成阈值，缺少三个中间环节：

1. 没有把“开仓、加仓、高抛、退出、市场仓位”分成独立标签；
2. 没有把一张图上的判断还原成高点以来的完整路径；
3. 每次修改后只验证当前案例，没有让所有既有正反样本自动回归。

因此，后续暂停“看到一只错单就增加一个阈值”的方式。每次策略修改必须依次经过：样本标准化、特征快照、形态归类、黄金样本回归、样本外验证、本地事件回放，最后才能进入 QMT 整段回测。

本文件是研究流程，不直接定义最终交易参数，也不构成投资建议。

## 2. 全局案例分析框架

单个案例不能只回答“有没有碰MA13”或“均线比例是多少”。每个案例都要放进同一个由上到下的分析立方体，最终结论必须能说明：当时是什么市场、什么板块、什么趋势阶段、什么回调路径、什么量价筹码、什么盘中触发，以及应该承担多大风险。

### 2.1 第一层：市场环境

需要记录：

- 沪深300、中证500、中证1000、创业板分别处于启动、趋势、轮动、退潮还是空头；
- 全市场上涨家数、跌停/涨停扩散、成交额变化；
- 当前是普涨、单主线、多个板块轮动还是全面退潮；
- 风格指数是刚转弱，还是已经弱势较长时间；
- 当时允许的组合总仓位区间。

相同的个股形态，在强板块主升期可能适合首仓，在指数刚转空、板块退潮期可能只能观察。因此市场层负责决定“能不能承担风险”和“最多承担多少”，不直接替代个股买点。

### 2.2 第二层：板块环境

需要记录：

- 板块相对四个风格指数及全市场的13/40日强弱；
- 板块内上涨股票占比、站上MA13/MA40占比；
- 领涨股、中位股、补涨股是否同步；
- 板块成交额是扩散、集中还是衰退；
- 当前是板块启动、主升、轮动回流、高位分歧还是退潮；
- 个股是板块前排、跟随还是逆板块独立行情。

板块层决定该形态的先验成功率。个股技术形态很好但板块已经退潮，不能与板块主升期的同形态使用相同评分和仓位。

### 2.3 第三层：个股长期背景与可交易性

需要记录：

- 20/60日流动性、停牌与涨跌停状态；
- 相对板块强弱、相对风格指数强弱；
- 近期波动率、ATR、跳空频率和可成交容量；
- 近40至60日处于底部启动、趋势中继、加速、高位派发还是趋势破坏；
- 当前是首次参与，还是已有主仓后的交易仓操作。

这一层用于排除“走势漂亮但不可参与”的过强、过弱或流动性不足股票，也防止把首次开仓与持仓加回混为一谈。

### 2.4 第四层：日线生命周期和路径

不能只截取买入当天。以最近一个有效启动点或阶段高点为锚，重建完整事件序列：

```text
启动/突破
→ 远离MA7的程度
→ 第一次回到MA7
→ 是否反弹、反弹多高
→ 是否形成平台和成交密集区
→ 第一次进入MA13
→ 支撑、失败或重新启动
```

这一层负责区分：首次深回、沿MA7趋势、二次回踩、平台破位、底部再启动和高位派发。只有先识别生命周期，后面的均线和30分钟指标才有明确含义。

### 2.5 第五层：空间、时间、量能和筹码四维结构

每个案例同时从四个维度判断：

| 维度 | 主要问题 | 典型指标 |
|---|---|---|
| 空间 | 高点到支撑是否有足够回撤，支撑上方是否还有反击空间 | 高点乖离、回撤深度、ATR距离、平台至MA13距离 |
| 时间 | 回调是第一次快速到位，还是已经反复消耗 | 高点后天数、MA7附近停留天数、反弹次数、平台天数 |
| 量能 | 回调是健康换手、恐慌抛售还是无量阴跌 | 回调累计成交额、上下跌量比、反弹量比、量价背离 |
| 筹码近似 | 上方是否积累大量短期套牢盘 | 成交密集区、平台换手、当前价上方一个ATR内成交额占比 |

不能因为某一个维度合格就下结论。例如回撤空间足够，但已在MA7附近反复十天并形成高换手平台，仍可能不是优质MA13首次回撤。

### 2.6 第六层：盘中行为

盘中只回答“今天的支撑是否正在被市场确认”，需要观察：

- 下探是主动抛压还是缩量试探；
- MA13被穿透的深度和持续时间；
- 反弹是否收复VWAP和关键价格区；
- 连续完整30分钟K是否抬高低点、抬高收盘；
- 反弹量是否足以覆盖下跌量；
- 尾盘是否重新失守。

盘中层不能挽救一个日线生命周期已经不合格的案例。

### 2.7 第七层：交易动作、仓位和执行约束

同一个信号必须同时给出动作级别：

- 只观察；
- 试仓10%至25%；
- 正常首仓；
- 已有主仓后的加仓/加回；
- 仅减交易仓；
- 减主仓；
- 清仓。

还要考虑T+1、可用股数、涨跌停、滑点、委托是否成交。不能把“形态判断正确”等同于“回测订单一定执行成功”。

### 2.8 第八层：后验评价

后验只评估判断质量，不允许参与当日信号。至少记录后续1、2、3、5、10日的MFE、MAE、是否先触发止损、是否保持在MA13/MA40上方，以及板块同期表现。

这样可以区分：

- 形态判断错误；
- 形态正确但市场/板块环境不利；
- 入场正确但仓位或退出错误；
- 信号正确但执行失败。

### 2.9 分层决策，而不是条件累加

最终模型不应是一个不断增长的布尔表达式。建议结构为：

```text
市场风险层：决定总仓位上限
→ 板块状态层：决定板块预算和先验质量
→ 个股生命周期分类器：决定属于哪类形态
→ 该形态的质量评分：空间 + 时间 + 量能 + 筹码
→ 盘中触发器：决定执行时间
→ 仓位/退出状态机：决定动作规模和失败处理
```

硬条件只保留数据完整性、流动性、停牌/涨跌停、明确趋势破坏等不可妥协项。空间、时间、量能和筹码的大多数差异进入形态内评分，避免一个阈值把所有边界样本机械切断。

### 2.10 用全体候选建立对照，而不是只研究用户样本

人工样本用于定义“我们想找的东西”，但指标阈值必须来自更大的对照集。每个正样本都应自动寻找：

- 同一天、同板块、相近强度但没有被选中的股票；
- 同一股票历史上相似均线位置的其他日期；
- 相同回撤深度但不同平台/量能结构的案例；
- 后续成功与失败各一组的匹配样本。

在不使用未来数据生成特征的前提下，可以对标准化的20日价格、均线距离和成交量路径做聚类或相似度检索，先观察自然形成了哪些形态族，再决定规则。人工样本不直接变成阈值，而是用于给这些形态族命名和解释。

### 3.5 市场与仓位样本是另一层问题

市场状态不能混入个股形态模型：

- 全面走弱时允许空窗，但这种情况相对少见；
- 只要仍有活跃板块就应该参与，弱势环境总仓位控制在约30%以内；
- 轮动市场中有一个明确强势指数/板块时，总仓位应随板块数量和强度提高到30%至60%；
- 沪深300或创业板刚进入明显空头阶段时，不适合激进开新仓；
- 个股跌破MA40或所属板块有效跌破MA40属于退出层硬约束。

这些判断需要单独的“市场状态样本日”，不能用个股买卖样本顺便推断。

## 4. 从样本得到的形态结论

### 4.1 优质MA13首次回撤是路径，不是位置

建议用状态机描述：

```text
趋势形成
→ 股价明显脱离MA7
→ 出现第一次有空间的快速回撤
→ 回撤途中没有在MA7附近形成多日平台或完成一次明显反弹
→ 首次进入MA13支撑带
→ 日内出现承接并持续站回
→ 次日仍有跟随，或者失败后快速退出
```

其中“直接回撤”不要求每天收阴，而是要求在高点到MA13之间没有形成足以积累大量套牢筹码的中间平台。

### 4.2 MA7/13与MA13/40的关系应表达“空间质量”

仅比较两段均线的瞬时比例不够。至少需要同时观察：

- 当前7/13、13/40的绝对距离；
- 两段距离过去3至5日的扩大/收缩速度；
- MA7、MA13、MA40各自斜率和曲率；
- 股价从高点回落过程中在MA7附近停留的天数；
- 中间反弹平台到MA13的可用空间。

短均线距离很小、13/40距离很大，通常说明短期趋势已衰减；但如果这是底部刚启动的7上穿13，则属于另一种形态，不能用首次深回撤规则处理。

### 4.3 上方套牢筹码需要独立量化

002155、002170、002237暴露的不是单纯均线问题，而是回调路径中的成交密集区问题。建议计算：

- `ma7_band_days`：高点后落在MA7上下某个ATR范围内的交易日数；
- `intermediate_bounce_count`：高点到MA13之间出现的有效反弹次数；
- `platform_days`：窄幅价格带内连续停留天数；
- `platform_turnover`：平台累计成交额/高点前5日平均成交额；
- `platform_to_ma13_room`：平台下沿到MA13的距离，以ATR和百分比双口径表达；
- `overhead_supply_ratio`：当前价上方一个ATR内的成交额占回调阶段成交额比例。

中间平台成交越集中、平台离MA13越近，MA13首次反击成功率越低。

### 4.4 30分钟只做执行确认

30分钟确认应使用标准完整K线，并至少记录：

- 首次下探MA13的穿透深度；
- 连续收盘是否站在日线MA13上方；
- 第二根是否创新低、是否收在K线下半区；
- 反弹成交量相对下跌成交量；
- 收盘相对当日VWAP的位置；
- 当日最后两根是否重新跌回支撑下方。

“两根站回”只能在日线路径合格后启用。入场当日收盘失败，或入场后1至2日迅速失守，应标记为独立的 `early_entry_failure`，按T+1处理交易仓。

### 4.5 高抛和主退出必须分层

- 30分钟冲高失败：只减交易仓；
- 日线MA7暂时跌破但MA13和MA40趋势完好：观察或小幅减仓；
- 多日无法收回MA13、MA7转负/下穿MA13：减主仓或退出；
- 个股或板块有效跌破MA40：硬退出。

## 5. 候选指标方向

以下指标先用于研究报告，不应一次全部写进实盘策略。

### 5.1 趋势与均线结构

- `distance_close_ma7/13/40`
- `gap_7_13`、`gap_13_40`
- `gap_ratio_raw = gap_7_13 / gap_13_40`
- `gap_speed_ratio`：按均线周期跨度归一后的开口速度比
- `slope_ma7_3d`、`slope_ma13_3d`、`slope_ma40_5d`
- `curvature_ma7`、`curvature_ma13`：当前斜率相对前一窗口的变化

### 5.2 高点至支撑的路径

- `days_from_peak`
- `peak_extension_ma7`：阶段高点相对当日MA7的乖离
- `pullback_depth_peak`
- `first_ma7_touch_day`、`first_ma13_touch_day`
- `ma7_band_days`
- `prior_ma13_touch_count`
- `intermediate_bounce_count`
- `direct_pullback_efficiency`：净回撤/路径总波动，越高越接近直接回撤

### 5.3 量能与筹码近似

- `correction_turnover_days`：回调累计成交额折算成高点前平均成交日数
- `down_volume / up_volume`
- `platform_turnover`
- `platform_range_atr`
- `platform_to_ma13_room_atr`
- `overhead_supply_ratio`
- `reclaim_volume / breakdown_volume`

### 5.4 盘中确认与失败

- `ma13_undercut_atr`
- `reclaim_bar_count`
- `reclaim_close_location`
- `reclaim_volume_ratio`
- `close_vs_vwap`
- `last_two_bars_above_ma13`
- `session_close_vs_ma13`
- `day1/day2_follow_through`

### 5.5 结果指标只用于评价，不得反向泄漏到信号

- 入场后1、2、3、5、10日最大有利变动MFE；
- 入场后1、2、3、5、10日最大不利变动MAE；
- 是否先达到+1 ATR还是先达到-1 ATR；
- 第1/2日是否有效跌破入场支撑；
- 交易仓、主仓分别的收益和持有时间。

## 6. 标准样本格式

以后每个样本至少记录：

```text
股票代码：
决策日期和时间：
动作：观察 / 首仓 / 加仓 / 加回 / 减交易仓 / 减主仓 / 清仓
形态类别：
当时可见的前置条件：
为什么可以或不可以：
预期仓位级别：
失效条件：
置信度：高 / 中 / 低
是否允许用次日结果校验：是，但不得用于当日特征
```

标签分两部分保存：

- `expert_label`：只描述当时应该做什么；
- `outcome_label`：记录未来表现，用于评估专家规则是否稳定。

不能因为后来上涨，就倒推当日一定是好买点；也不能因为后来下跌，就自动把当日标为错误。

## 7. 每一轮研究的执行步骤

### 步骤0：冻结基线

记录策略版本、提交号、数据版本、回测区间和当前信号数量。研究期间不同时修改选股、入场、退出和仓位四个层级。

### 步骤1：标准化全部人工样本

将本文件中的所有样本写入机器可读标签库。日期不确定的样本保持 `unresolved`，不允许为了方便随意猜日期。

完成标准：每个高置信样本有唯一代码、日期/时间、动作、形态和失效条件。

### 步骤2：统一数据口径

使用同一份QMT导出数据：

- 日线用于MA7/13/40与板块/指数结构；
- 不复权5分钟线用于真实成交和30分钟合成；
- 复权日线均线换算到不复权价格坐标；
- 30分钟严格按09:35至10:00等标准完整区间聚合；
- 每个特征只读取决策时点之前的数据。

完成标准：任意样本都能输出日线、30分钟K、MA值和价格坐标审计表。

### 步骤3：生成样本特征快照

为每个样本提取前20至40个交易日、当日截至决策时刻的5分钟数据，以及后续评价窗口。生成统一CSV/JSON，不先做买卖判断。

完成标准：正反样本可以并排比较，缺失字段有明确原因。

### 步骤4：先做成对研究

优先比较最接近的正反例：

- 301592（正）对002155/002170/002237（反）；
- 300236的2025-08-04（正）对2025-10-14（反）；
- 002643/002056（盘中确认失败）对真正持续收复样本；
- 天赐材料加回（正）对普通首次开仓反例。

每次只回答一个问题，例如“上方平台如何区分”，不同时优化所有指标。

### 步骤5：形成独立形态模型

至少拆分为：

1. 首次深回MA13；
2. MA7支撑趋势延续；
3. MA40/底部再启动；
4. 持仓后的MA7/MA13加回；
5. 30分钟高抛；
6. 入场后早期失败；
7. 日线主退出。

每类模型由三部分组成：硬否决、质量评分、执行确认。不同模型不得共享一个含义模糊的总分。

### 步骤6：运行黄金样本回归

每次修改都输出：

| 样本 | 预期 | 实际 | 分数 | 通过/拒绝原因 | 是否回归 |
|---|---|---|---:|---|---|

完成标准：高置信正样本和反样本全部有可解释结果。若为了修复一个样本破坏另一个样本，本轮不能进入整段回测。

### 步骤7：扩充邻近反例和样本外数据

从同板块、相近日期、相似均线位置自动抽取邻近样本。人工样本用于提出假设，邻近样本用于验证规则没有只记住代码和日期。

建议按股票和时间分组，保留至少30%的样本完全不参与参数设定。

### 步骤8：本地事件回放

在挂载的QMT数据上按时间逐根回放，模拟：

- 只能使用当时已完成的K线；
- 下一根可成交价格；
- A股T+1；
- 涨跌停、停牌、最小100股；
- 手续费与滑点；
- 委托、成交、持仓三种状态分离。

完成标准：能解释每笔订单从候选、触发、委托到成交/失败的全链路。

### 步骤9：最后才做组合回测

依次评估：

1. 单形态命中率、MFE、MAE；
2. 多形态合并后是否互相冲突；
3. 板块与市场仓位控制；
4. 收益、回撤、换手、持仓集中度；
5. 样本内与样本外差异。

目标不是先追求年化100%，而是先证明信号有稳定的正期望和可解释的风险。收益目标只能建立在样本外结果之上。

### 步骤10：QMT验证与版本发布

本地通过后才同步QMT。每个版本只修改一个规则族，并提交：

- 版本号与日期；
- 规则变化；
- 黄金样本回归结果；
- 新增/删除信号数量；
- 本地事件回放结果；
- QMT日志与成交明细；
- 已知限制。

## 8. 进入下一阶段的验收门槛

一次修改只有同时满足以下条件才算有效：

1. 高置信正样本没有无解释地丢失；
2. 指定反样本不再错误触发；
3. 新增和删除的全部信号数量可见，不能只看收益率；
4. 随机抽查至少20个新增或保留信号的K线；
5. 样本外结果没有明显恶化；
6. 日线信号、30分钟确认、执行、退出分别有原因码；
7. 整段收益改善不能来自少数异常大单或未来数据泄漏。

如果黄金样本通过但整段结果变差，先检查新增/删除了哪些形态，不立即继续调阈值。如果整段结果变好但反样本仍大量触发，也不能视为完成。
