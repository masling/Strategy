# QMT 多风格 7/13/40 均线轮动策略 v2.5.0

发布日期：2026-08-13

这是一版运行在 QMT 内置 Python 中的 A 股结构性行情策略。默认配置为 `BACKTEST`，不会主动向模拟或真实账户报单。

> 仅用于策略研究和模拟验证，不构成投资建议。

## 核心逻辑

```text
指数独立判断各风格开仓风险
→ 通过风险门的指数成分股与活跃申万行业取交集
→ 活跃行业数量和强度决定风格仓位
→ 建立持续强股观察池，与当日买点分离
→ 日线先筛选强势且结构合格的观察股，首次MA13回收须由盘中确认
→ 本地 5 分钟数据合成完整 30 分钟K线
→ 两根30分钟K稳定收复日线MA13后小仓首入；顶部确认后减仓，回踩日线支撑并企稳后加回
```

### 1. 指数判断风险，板块决定仓位

沪深300、中证500、中证1000和创业板指分别评分，弱势指数不能否决强势指数中的机会。

| 原状态 | 连续条件 | 新状态 |
|---:|---:|---:|
| 关闭 | 得分≥75持续2日 | 观察 |
| 观察 | 得分≥85持续2日 | 强势 |
| 强势 | 得分＜75持续2日 | 观察 |
| 观察 | 得分＜65持续2日 | 关闭 |

风险门使用迟滞状态机，不再因为单日评分跨线就在70分加满、65分清仓。强势状态首日跌破75分时，单风格先降到最高30%；强势降为观察且评分低于65时，再降到最高15%；只有观察状态连续2日低于65才关闭该风格。这些阶段性减仓记为 `risk_reduce`，个股MA40破位和ATR止损仍可立即退出。

风格从关闭激活或最终关闭时立即重算强股观察池；观察/强势之间的切换只改仓位上限。观察池按5个交易日周期重算，但入场形态每日重算，不再要求股票在5日扫描当天恰好出现买点。

通过风险门后，实际仓位由活跃申万行业的数量和强度决定：

| 指数状态 | 活跃行业 | 单风格目标仓位 |
|---|---:|---:|
| 观察 | 1 / 2 / 3个 | 20% / 30% / 30%（风险上限） |
| 强势 | 1 / 2 / 3个 | 30% / 40% / 50% |
| 强势且至少2个行业整体强 | 2 / 3个 | 50% / 60% |
| 全市场只有1个明确主线板块 | 主线65～75 / ≥75分 | 30% / 60%（再受承载指数风险帽限制） |

四个风格都未通过风险门时保持空仓。多个风格同时活跃时，合计仓位仍以80%为硬上限，超出后按比例缩放。

指数评分只使用日线7/13/40均线，不再请求周线和月线。价格必须在MA40上方且MA40方向向上，否则即使短期急反弹也不会激活该风格。

### 2. 风格与行业取交集

每个激活风格分别计算：

```text
风格指数成分股 ∩ SW1申万一级行业成分股
```

行业代理曲线由交集内股票的每日收益率等权合成，再按13日和40日相对强弱、均线趋势、成交额和过热程度排序。每个风格最多选择3个行业。

### 3. 个股日线规则

v2.0.0将“强股选择”和“实际买点”拆成两层：

- 观察池只要求MA40向上、MA13位于MA40上方、13日与40日相对强度为正、流动性合格，且不处于过度远离MA40的位置；
- 进入观察池不等于下单，只有每日重算后形成 `trend`、`ma40_starter` 或 `base_reclaim` 才标记为 `ENTRY_READY`；
- 未出现买点的股票保留在观察池等待MA13/MA7回调，不会抢占真实仓位；
- 已持仓股票在下次排名下降时继续保留，不再仅因为掉出5日候选排名就卖出。

v2.0.1不再沿用5日观察池刷新时的旧评分，每个交易日都重算当日评分。v2.1.0进一步把评分拆成两条独立轴：`strength_score` 表示股票阶段强度，`entry_score` 表示当前位置是否适合这套均线策略参与。

v2.1.0将每个风格的观察池从6只扩大到12只、单行业观察上限从2只扩大到4只，但真实持仓上限仍为每风格4只。这样可以同时跟踪更多强股，等它们回到MA7/MA13或MA40启动位置，而不是为了扩大观察池就增加实际仓位。

v2.1.1修复流动性有效成交额计算中 `amount` 数组未初始化导致日线选股中断的问题，不改变v2.1.0的策略参数。

v2.2.0将开仓评分调整为入场适配度70%、强度适配度30%。强度不再“越高越好”，而是以70分附近为最优；60和80分仍可参与，但适配贡献降低。普通趋势开仓还要求原始强度在35～90之间、综合分不低于65；MA40启动与底部收复允许强度25～92、综合分不低于60。强度过高标记为 `OVERPOWERED`，不追加速段。

v2.2.0同时建立每风格30只的强股储备池，再按当日入场适配度选出12只可交易观察股。`OVEREXTENDED`、`OVERPOWERED` 和 `VOLUME_WAIT` 只进入 `SPECTATORS` 观赏日志，不占可交易观察名额。储备股在5日刷新周期内若只是暂时相对强度或均线结构不合格，保留等待而不从池中删除；只有数据、停牌、ST或绝对流动性硬条件失效才剔除。

已持仓股票改用黏性目标股数：新买点出现或消失时只增加新机会，不再重新拆分所有旧持仓。单风格仓位下调小于3个百分点时不触发持仓减量；达到门槛、风格关闭或个股风控条件成立时才有序减仓。

v2.3.0新增“唯一主线集中仓位”。策略先合并四个风格指数中重复出现的同一申万板块，不重复计算仓位。第一名板块至少65分，且第二名低于60分或两者差距至少15分时，识别为唯一主线；主线65～75分给30%基础目标，75分及以上给60%。如果承载该板块的风格指数尚在观察或警戒状态，60%仍会被风险帽压到30%或15%。

新开仓要求：

- 普通趋势开仓时，信号收盘价最多高于MA7 4%；
- 普通趋势开仓还要求MA7连续两日上行、MA7/MA13开口不超过3.5%，且价格最多高于MA40 15%；
- MA40启动允许盘中低点在MA40上下3.5%内完成支撑确认，以覆盖筑底后的放量突破；
- 启动仓补仓和30分钟减仓后加回都优先等待MA13；MA7只在高点之后已回撤至少6%且MA7未转向时允许使用；
- MA7加仓还要求MA7/MA13开口为MA13/MA40开口的50%～125%，且MA7不高于MA40 18%；短均线过于靠拢而MA13/MA40距离较远时，只等MA13支撑；
- MA40启动和底部收复允许最多高于MA7 8%，以保留支撑位放量突破；
- 实际下单价还会再校验MA7乖离，且不得比信号收盘价高出3%，防止次日跳空或旧候选重试造成追高。
- v1.8.1开始，上述执行价校验不再把不复权真实成交价与后复权MA直接比较。策略额外读取信号日的不复权收盘价，将MA7、MA40和信号收盘统一换算到真实价格坐标后再校验。原始价缺失时不允许开新仓。

```text
收盘价 > MA7 > MA13 > MA40
MA13方向向上
MA40方向向上
13日、40日均跑赢所属风格行业
20日平均成交额达到门槛
收盘价相对MA40的乖离不超过25%
MA7与MA13的开口不能明显大于MA13与MA40的开口
MA7和MA13的近3日斜率必须继续向上
```

强度分主要看相对强弱、阶段涨幅、近期高点位置、流动性和波动率；入场分主要看收盘与日内低点距MA7/MA13的位置、7/13与13/40开口是否流畅、MA7/MA13斜率、20日平均成交额及近5日量能比。明显远离MA7/MA13/MA40的过度强势股标记为 `OVEREXTENDED`；强度超过适合参与的加速区间标记为 `OVERPOWERED`；近5日成交额不到20日均值的40%，或高于250%，标记为 `VOLUME_WAIT`。这些股票留在储备池和观赏日志，但不占可交易观察位。

绝对流动性不足的股票不进观察池，不使用等待状态占用名额。流动性以最近20日窗口内有效交易日的平均成交额判断，计算时排除停牌日和涨跌停日，避免它们的特殊成交量把正常流动性压低或抬高。最近20日窗口至少需要10个正常交易日，否则也直接排除。

另外保留一类独立的“MA40启动仓”，用于识别天赐材料2026年4月10日、盐湖股份2025年12月17日类似形态：股价回踩上行的MA40后收回MA13上方，MA40继续上行，MA7与MA13已经收敛，并且收盘突破前一日高点。由于位置接近MA40，MA13近3日斜率可以轻微向下，但只建立50%目标仓位。

v2.4.6 修正首次 MA13 深回撤的“首次触及”定义：只统计阶段高点之后、且实际进入 MA13 支撑带的回踩；峰值前上涨过程中的均线靠近，以及高于支撑带的普通回落不再误判为第二次回踩。此类信号仍只试仓 40%，并将 MA40 乖离独立限制为 16%、均线开口速度比限制为 3.0；普通 MA7/MA13 回踩仍保持 15% MA40 乖离与更严格的开口限制。该修正恢复 301592、300573 这类首次深回撤样本的试仓资格，仍保留消化时间、量价和反弹力度限制。

v2.4.7 增加 30 分钟“低量冲高失败”交易仓减仓：先出现成交量至少为前 20 根均量 2.5 倍的冲高，再出现创新高但长上影、且成交量不超过冲高 K 线一半的弱确认，随后一根收盘跌破该弱确认 K 线低点。它以 `intraday_exhaustion_top` 记录，只减交易仓三分之一；原有盈利、日线趋势和均线乖离保护继续生效。

v2.4.8 兼容国金 QMT 内置旧版 pandas：首次 MA13 深回撤计算不再调用旧版缺失的 `Series.to_numpy()`，改用 `np.asarray()`。该版本只修复运行兼容性，不改变任何选股、买卖或仓位规则。

v2.4.9 将 MA13 支撑类日线信号与实际首仓分离。日线储备池中 MA7>MA13>MA40、MA13/MA40仍向上的股票，会在盘中继续观察；MA13 回踩/首次深回撤的首次试仓均等待同一交易日两根完整30分钟K在已换算的不复权日线MA13上方稳定收回，第二根须收强且量能不得明显衰减。这样可在回踩当日参与 301592、300236 一类 MA13 获得盘中支撑的机会，同时阻止 002643 一类无法收复 MA13 的日线候选在早盘直接下单。首次仓位固定为该股常规目标的35%。MA40启动和底部试仓不受该确认门限制。

v2.4.9 同时将 MA13 失守后的观察期改为三个完整交易日：第三日仍无反抽站回才减半，第四日仍未收回才清理。30分钟减仓补充“远离日线MA7后的无量冲高失败”：冲高K已高于MA7至少8%、量能不高于前20根均量的1.2倍、出现长上影，后一根跌破其低点时减去交易仓三分之一。

v2.5.0 收紧盘中 MA13 回收观察池：不再把所有日线多头排列的储备股交给30分钟确认。只有近期高点后第3～5日、此前未触及MA13、回撤深度至少5%、高点相对MA7至少扩张6%、回调成交额达到高位平均两日以上且“首次深回撤分”至少85分的股票，才进入盘中观察。MA7/MA13开口还必须不小于MA13/MA40开口的45%，排除连续沿MA7走弱、短均线空间过窄而MA13/MA40距离过大的伪回踩。这会排除002056、002155、002170、002237一类盘中短暂收复但日线回调路径不干净的买点，同时保留301592一类真正的首次深回MA13候选。

盘中首仓若在当日14:30前已出现连续两根30分钟K收于对应日线MA13下方，则记录 `INTRADAY_ENTRY_FAIL_MARK`。A股当日买入不可卖时不做无效委托，下一交易日可卖后以 `intraday_entry_early_failure` 减半；若当日已有可用持仓则直接减半。保护窗口覆盖入场当日及随后两个交易日附近，避免回收失败的小仓继续拖成日线级别亏损。

启动仓建立后的15个交易日内，MA7/MA13加仓改为盘中确认：支撑位始终使用已完成的日线MA7和日线MA13，30分钟K线只负责判断是否站稳。价格回踩日线支撑后，连续两根同一交易日的完整30分钟K线收在对应日线上方，且第二根未转弱，当日即把剩余50%目标仓位加满。委托原因分别记为 `trend_add_ma7` 和 `trend_add_ma13`。超过15个交易日不再追加。

盘中加仓后保留该次新增股数。当日收盘仍在对应日线上方时直接确认；如果收盘又跌回支撑下方，次日上午前两根30分钟K线在10:30仍未连续站回当时的日线MA7/MA13，则以 `build_add_unconfirmed` 卖出仅这次新增部分，保留原启动仓。该处利用A股T+1，不会尝试当日卖出新增仓位。

如果经历一段调整后MA7重新站上MA13，MA40继续上行，价格从收敛均线上方突破整理区，则识别为“二次启动”，并重置上一轮的建仓过程。盐湖股份2026年2月24日属于该形态：先建立50%新启动仓；若后续3个交易日内MA13重新向上且价格继续突破，以 `trend_add_resume` 补齐剩余仓位。

每个风格先保留最多30只储备股，再选出最多12只可交易观察股，并跳过按单股仓位上限买不到一手的高价股。每个风格最多4只真实持仓；单行业最多观察4只，单只持仓最高15%。某风格没有合格且可执行的买点时，对应预算保留为现金，不会为满仓而买入等待中的观察股。

### 4. 5分钟合成30分钟

QMT补充数据没有30分钟选项，因此策略只读取 `5m`，按A股固定交易时段每6根合成一根完整30分钟K线：

- 上午：10:00、10:30、11:00、11:30；
- 下午：13:30、14:00、14:30；
- 不跨午休拼接；
- 少于6根的未完成桶直接丢弃；
- 15:00收盘桶不在当天报单，避免回测使用现实中无法成交的收盘后信号。

30分钟顶部采用两步确认：前一根成交量不低于前20根均量的1.8倍，并出现冲高回撤、长上影或收在K线下半部；后一根收盘跌破信号K线低点。确认后减仓约三分之一，不直接清仓。v2.0.0还要求当前价至少高于持仓成本3%，且信号高点确实远离日线MA7和MA13；亏损中不再以 `intraday_top` 减仓。

5分钟和合成的30分钟K线统一使用不复权价格，与已换算到真实价格坐标的日线MA7/MA13/MA40和成交价保持一致。

只有当顶部减仓前价格确实远离MA7和MA13，且日线MA7 > MA13 > MA40、MA7和MA13近3日斜率仍向上时，才建立回补计划。回补不再一次性完成：

> 本节所有“MA7/MA13”均指日线均线，不是30分钟均线。30分钟K线只用于确认止跌、站稳和反转。

- 回落MA7附近并出现30分钟止跌反转时，先加回减仓量的50%；
- 继续回落MA13附近并反转时，加回剩余部分；
- 如果首次回补后直接重新站上MA7并向上突破，不必等待MA13，直接补齐剩余部分；
- 回补窗口只保留3个交易日。超时后停止新增回补；如果只补了一部分，价格反弹到MA7上方时卖出该加仓部分。

### 5. 退出规则

- 保留2 ATR紧急止损；
- 收盘跌破MA40立即退出；
- 跌破MA13后保留三个完整交易日等待反抽；第三日仍无反抽站回先减半；
- 连续四日位于MA13下方仍未收回则清仓；
- 所属风格最终失效时退出；仅因5日排名下降或行业名次轮换不再机械退出；
- 已删除盈利12%固定止盈；
- 已删除持有20天强制卖出；
- 已删除2.5 ATR移动止盈，避免过早卖掉持续趋势股。

## QMT需要补充的数据

在“操作 → 数据管理”中准备：

1. 下载“全部板块”分类，确保能读取 `沪深300`、`中证500`、`中证1000`、`创业板` 和31个 `SW1...` 行业板块。
2. 为 `000300.SH`、`000905.SH`、`000852.SH`、`399006.SZ` 以及沪深A股下载日线。
3. 为回测期间可能入选的沪深A股下载5分钟数据。回测日期较长时，5分钟数据量会明显大于日线。
4. 1分钟数据不是本版本的依赖，可以不下载。
5. 不需要周线、月线、30分钟线、`BKZS`行业指数。
6. 建议补充历史ST数据，否则历史ST过滤可能退化为当前证券名称判断。

日线建议至少比回测起始日提前60个交易日；5分钟数据必须覆盖完整回测区间。

## 回测方法

1. 在QMT新建Python策略，复制 `qmt_multicycle_strategy.py` 全部内容。
2. 保持 `RUN_MODE = "BACKTEST"`。
3. 主图选择 `000300.SH`，周期必须选择“5分钟”。
4. 在策略编辑器的回测参数面板设置开始时间和结束时间；代码不会写死或覆盖日期。
5. 配置资金、佣金、税费和滑点后运行。
6. 首先检查日志，不要只看收益曲线。

策略会读取界面传入的 `ContextInfo.start/end` 作为保护边界，即使引擎额外传入区间外K线也会跳过。回测模式若主图不是 `5m` 会直接报错，避免误用日线从主图最早历史开始运行。

回测账户使用QMT示例兼容的 `testS`，并通过 `order_shares()` 提交买卖信号，以便券商版QMT在回测结果页生成交易明细和K线买卖点。模拟运行仍通过 `passorder()` 向绑定的模拟账户发送委托。

选股和趋势形态计算使用后复权序列，但凡是要与实际委托价、持仓成本或盘中30分钟K线比较的 MA7/MA13/MA40、ATR和近期高点，都会先换算到当日不复权原始价坐标。目标股数和 `order_shares()` 固定价也使用当前5分钟原始价。原始价缺失时，新开仓和依赖该坐标的风控判断会安全跳过。

日线调仓、风控退出和30分钟盘中信号都不在信号K线上成交。策略先记录 `ORDER_QUEUED`，再于下一根5分钟K线的开盘价执行。回测默认叠加10个基点的单边不利滑点：买入价上调，卖出价下调。如果目标滑点价超出下一根5分钟K线的高低范围，使用该K线内可成交的最不利价（买入取最高价、卖出取最低价），避免QMT将越界指定价自动替换成最新价。如果下一根K线跳空后超过入场乖离上限，该笔新开仓会取消。

部分券商版QMT在正式回测中会把界面初始资金暴露为 `ContextInfo.capital=-1`。策略优先使用界面返回的正数资金；仅当该值无效时，才在 `init()` 中写入 `BACKTEST_INITIAL_CAPITAL`，默认为100万元，并输出 `WARNING invalid context.capital`。如需改变回测资金，请同时调整界面金额和该备用参数。

同一股票、同一方向在同一根K线上只允许提交一次，避免风险退出后又被调仓逻辑重复提交。旧版 `ORDER` 日志仍可由Web分析器读取；从v1.6.3开始应优先用 `DEAL` 判断是否真实成交。

建议分别回测大盘占优、中小盘占优、成长占优、全面下跌和震荡期，并测试0.10%、0.20%、0.30%三档滑点。

回测持仓优先读取QMT虚拟账户的 `m_nCanUseVolume`，不会再把总持仓
`m_nVolume` 当作可卖数量。若券商版无法返回虚拟账户对象，备用路径会从
总持仓中扣除当日买入成交量，以遵守A股T+1；因此当日新买股票触发30分钟
顶部信号时会跳过卖出，不会向QMT提交无效卖单。

## 模拟账户

回测和日志验证完成后：

1. 把 `RUN_MODE` 改为 `SIMULATION`；
2. 绑定专用模拟账户；
3. 主图继续使用5分钟；
4. 先用小额资金核对股票、方向、数量和委托时点；
5. 不要与人工持仓混用。

QMT“模拟信号模式”只记录信号。需要模拟柜台实际接收委托时，应确认绑定的是模拟账户并使用对应交易执行模式，绝对不要误绑真实资金账户。

## 已知限制

- 风格指数和申万行业读取的是当前成分股，历史回测存在成分穿越与幸存者偏差，向前模拟更重要。
- 行业代理曲线是当前成分股等权合成，不等同于官方市值加权申万指数。
- 30分钟K线由本地5分钟数据合成；5分钟历史不完整时，策略会丢弃对应30分钟桶，可能减少盘中信号。
- 策略重启后可以从账户恢复成本和持仓，但MA13跌破计数、盘中减仓状态与启动仓次日1小时确认状态会重新开始累计。
- 内置Python策略依赖QMT客户端、Windows电脑和网络持续运行。
