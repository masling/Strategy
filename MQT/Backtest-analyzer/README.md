# QMT Backtest Analyzer

读取 `MQT/均线策略/qmt_multicycle_strategy.py` 输出的回测日志，并按交易日联动展示：

- 大盘全局仓位和各风格评分/仓位；
- 入选板块及评分；
- 入选个股、评分和目标股数；
- 账户资金、仓位实现率及未分配资金；
- 个股委托、盘中加减仓及对应日K标记；
- 东方财富公开数据源的日K和最近交易日分时。

## 本地运行

```bash
cd MQT/Backtest-analyzer
npm test
npm run build
npm run dev
```

打开 `http://localhost:4173`，导入QMT回测输出的 `.log` / `.txt` 文件，或直接粘贴日志。

## 数据说明

- 日K会按所选回测日期截断，避免看到未来行情；
- 公开接口不能可靠提供任意历史日期的完整分时，因此“分时”只展示最近交易日，并在页面明确标注；
- `ORDER` 表示策略已提交委托请求，不等同于成交。是否成交仍以QMT交易明细或 `dealdetails` 为准；
- 行情接口不可用时，页面保留日志分析结果并明确报错，不会生成虚构行情。
