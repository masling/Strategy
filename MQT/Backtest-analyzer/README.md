# QMT Backtest Analyzer

当前版本：`V2.3.1`（2026-08-13）

读取 `MQT/均线策略/qmt_multicycle_strategy.py` 输出的回测日志，页面分为三个工作区：

- 日期复盘：按交易日查看指数评分、风险状态、目标仓位和指数日K；
- 日期默认从最早交易日开始，可用“上一天 / 下一天”按钮连续逐日复盘；
- 板块复盘：联动所选指数，查看板块评分、唯一主线、策略等权代理K线和评分历史；
- 候选股复盘：在观察池表格直接点击个股，同页查看截止当日的日K及 MA7/13/40，并可跳转完整操盘明细；
- 个股操盘：可按股票代码或名称过滤有买卖记录的股票；筛选结果唯一时自动切换至该股。
- 个股观察池：展示综合分、强度分、强度匹配分、入场分与入场状态；
- 个股操盘：独立查看全部买卖时间、股数、价格、委托/成交/失败状态和K线落点；
- 样本采集：从当前市场、板块、候选股或个股K线发起标准化判断记录；
- 个股日K和30分钟K支持点击标点，保存当根K线、候选评分以及当日指数/板块上下文；
- 所有K线图底部显示成交量柱，并叠加VMA5/VMA20量能均线；量柱颜色与当根K线涨跌一致；
- 样本按市场判断、板块判断、个股选择和买卖点分层，记录正反结论、预期动作、形态、仓位、判断维度、原因与失效条件；
- 样本表单按市场环境、板块阶段、个股生命周期、回调路径、空间、时间、均线、量能、筹码和盘中确认逐层填写；
- 不同判断层级执行对应的完整度校验，未完成的“待判断”字段不会被误存为可分析样本；
- 个股K线标点后自动计算日线MA7/13/40、三日斜率、均线间距比、距20日高点、量比和MA13收复状态；30分钟标点同样以当日的日线均线为依据；
- 样本自动保存在浏览器本地，可编辑、删除，支持导入现有 `manual_labels.json`，并导出研究用JSON/CSV；
- 账户资金、仓位实现率及未分配资金；
- 在日K和可用的30分钟K上标出全部买卖点及委托时间；
- 同一根K线存在多笔记录时显示 `B×N` / `S×N`；
- 腾讯财经公开数据源的日K和30分钟K，分钟K读取上限扩大到640根。

## 本地运行

```bash
cd MQT/Backtest-analyzer
npm test
npm run build
npm run dev
```

打开 `http://localhost:4173`，导入QMT回测输出的 `.log` / `.txt` 文件，或直接粘贴日志。

直接粘贴时，点击页面顶部的“直接粘贴日志”，粘贴完后点击“解析日志”；也可使用 `Ctrl/Cmd + Enter` 直接解析。

## 样本采集

1. 在“日期复盘”选择交易日、指数、板块和候选股；
2. 使用“记录当前市场/板块判断”或“采集当前候选”预填上下文；
3. 需要精确到买卖点时，在“个股操盘”点击“在K线上标点采样”，再点击目标日K或30分钟K；
4. 填写当时可见的判断原因和失效条件后保存；
5. 在“样本采集”工作区导出JSON供事件回放，或导出CSV做特征比较。

浏览器本地样本不随日志重新解析而丢失。更换浏览器或清理站点数据前，应先导出JSON备份。

V2.2保存的浏览器样本会自动迁移到V3结构；历史样本不会丢失，但再次编辑时需要补齐新增的结构化字段。样本库会区分“可分析”和“待补全”，JSON/CSV也带有 `analysis_ready` 与缺失字段，避免旧样本混入正式统计。CSV已经为所有枚举和自动计算指标提供独立列，可直接用于分组统计。

## 数据说明

- 日K会按所选回测日期截断，避免看到未来行情；
- 日K使用前复权数据并按回测日期截断；腾讯公开接口的30分钟K只提供近期区间，页面会显示实际起止时间；
- 兼容QMT为日志行添加的 `【运行时间】` 前缀，不会再漏掉带前缀的目标仓位、委托和日状态；
- 兼容 V2.3.0 日志的 `regimes` / `risk_caps` / `SECTOR_FOCUS` / `WATCHLIST` / `SPECTATORS` / `ENTRY_READY` 多维评分；
- 策略日志在非调仓日不重复输出板块和观察池，Web会按 `STATE` 中的数量自动延用上次快照；
- 板块K线依赖 V2.4.1 策略日志中的 `SECTOR_K`，它与板块评分同样由 QMT 申万成员股等权代理行情生成；旧日志自动回退到评分趋势；
- 旧日志未包含个股所属申万板块时，个股观察池按指数展示，页面会明确提示，不会伪造板块归属；
- `ORDER` / `ORDER_SUBMITTED` 表示策略已提交委托；`DEAL` 才表示实际成交。有成交记录时，图表只画成交点；
- 日志出现“无持仓”或“行情不可用并跳过”时，对应委托标为明确失败且不画买卖点；
- 年化收益优先按回测开始、结束日期的实际自然日跨度计算；日期区间缺失时才按252个交易日折算；
- V1.5.5策略日志的 `ORDER` 包含K线时间和委托价；旧日志仍可解析，但只能把买卖点标在对应交易日；
- 行情接口不可用时，页面保留日志分析结果并明确报错，不会生成虚构行情。
