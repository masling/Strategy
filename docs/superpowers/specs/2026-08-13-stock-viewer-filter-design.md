# 个股操盘代码过滤

## 目标

让用户在“个股操盘”模块通过股票代码或名称快速缩小股票下拉列表，而不改变现有的K线、交易明细和买卖点展示逻辑。

## 交互

- 在股票下拉框前增加一个文本输入框，提示为“输入代码或名称”。
- 输入内容后实时以不区分大小写的包含匹配过滤股票代码和名称。
- 输入 `000792`、`000792.SZ` 或“盐湖”都应匹配 `000792.SZ 盐湖股份`。
- 清空输入恢复全部有操盘记录的股票。
- 无匹配项时，下拉框显示“无匹配股票”且不可选择。
- 已选股票被过滤掉且筛选结果恰好只剩一只股票时，自动切换至该股并刷新K线和交易明细；多只或无结果时，当前K线和交易明细保持不变。

## 实现边界

- 仅修改 Backtest Analyzer 的个股操盘选择器。
- 复用 `state.report.stocks` 作为唯一数据来源，不增加行情请求、不改变日志解析。
- 保持原生输入框与原生下拉框，避免引入组件依赖。

## 验收

- 代码与中文名称均可过滤。
- 过滤后选择股票，图表和交易账本切换到正确股票。
- 无匹配与清空筛选状态正确。
- 现有解析器测试和Web构建继续通过。
